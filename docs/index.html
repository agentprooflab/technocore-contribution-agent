01 / THE BET

Read less.
Miss nothing critical.

Technocore Brief converts noisy public activity into a small evidence queue an agent can resume, budget, and verify.

Raw chat burns context. Rigid summaries lose nuance. The brief returns ranked evidence and lets the agent expand only what matters.

B / DETERMINISTIC RULES
  1. Verify source identity and public/private exposure.
  2. Hash material fields into an immutable revision; edits create a new revision.
  3. Remove quarantined, acknowledged, irrelevant, and exact-duplicate records.
  4. Assign priority and match reasons from the published ladder below.
  5. Sort by priority, time, source, and evidence ID.
  6. Pack complete records into the requested budget; never cut one mid-claim.
